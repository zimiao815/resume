## 板级调试与系统集成

从开发环境搭建开始，进行基板调试、各硬件接口的适配与调通，并参与软件及硬件指标验证。在此基础上完成系统和业务软件适配，具体包括：

- U-Boot 与开机流程调整，eMMC 分区规划。
- Device Tree 配置、设备初始化与内存布局调整。
- 内核裁剪、相关内核模块适配、软件包增减与开发。
- 开源软件工具的 Bug 修复、业务软件移植与系统集成。

## 双系统升级与启动容灾

负责设计并实现基于 U-Boot Environment 的双系统升级机制，记录启动次数，并在连续启动失败时切换备用系统。方案覆盖启动状态记录、失败判定和系统切换，改善设备升级异常及启动失败后的恢复能力。

该部分与 eMMC 分区规划、启动流程和 OTA 软件共同组成产品升级链路。

## 内存与系统运行优化

在 512M 物理内存的硬件上，调整 DTS 内存布局、禁用未使用的 WiFi Radio 设备描述，使系统启动初期的 `MemTotal` 从约 310M 增至 430M。

进一步通过内核模块裁剪、业务程序内存泄漏修复、减少 C 代码中的 Shell 调用及功能模块重构，降低运行占用，改善内存压力和高 I/O 等待引起的卡顿，使产品支持 PCDN 业务运行并保障用户体验。

[查看这次优化的分析过程与指标口径](troubleshooting.md#系统内存与-pcdn-业务运行优化)
