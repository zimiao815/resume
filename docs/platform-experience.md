### AP 管理服务端与设备端

使用 Linux C 开发 AP 控制管理的两端程序。服务端通过二层广播发送探测报文，携带服务地址和端口；AP 收到后主动建立 TCP 连接，接收配置并定时发送心跳。

服务端维护 AP 状态和哈希表，将设备信息写入 MySQL，并根据配置更新向设备下发参数；连接断开后更新在线状态。该项目涉及二层通信、Socket、状态管理与数据库基础操作。

### 热点认证与网络应用

基于 Wifidog 开发无线热点认证功能，结合 iptables 和 HTTP 重定向实现接入认证，支持短信认证放行、黑白名单以及同一场所不同热点间免重复认证。

同时开发运行监控及异常处理脚本、设备配置页面；参与 nDPI 业务改造与协议解析，以及基于 802.11 监听数据的 WiFi 探针开发。
