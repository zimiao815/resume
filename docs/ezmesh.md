# ezMesh 统一组网平台

[返回首页](../README.md) · [查看简历](../resume.md)

## 背景与个人职责

公司路由器采用 Qualcomm 和 MediaTek 等不同平台，需要提供统一的 Mesh 组网与管理能力，并支持跨品牌混合组网。

我负责独立 ezMesh 管理进程、业务架构及 Controller 业务逻辑的设计与开发，在项目中承担主导性协作，处理组网和漫游相关问题，并配合完成中国联通 EasyMesh 认证。

## 管理进程与业务状态

ezMesh 管理进程承担 Controller 管理、Agent 节点管理、Mesh 状态维护、网络状态同步和业务控制，统一管理多平台产品的组网业务。

围绕用户入口，实现按键一键组网、App 组网和 Web 页面组网；围绕节点协作，处理心跳、网络通畅状态检测及业务状态同步。

## IEEE 1905 协议扩展

项目使用原厂 IEEE 1905 协议栈。我在已有协议栈基础上扩展私有 TLV，用于心跳、网络状态同步、私有业务控制及自定义消息交互，满足产品层面的组网管理需求。

标准协议栈由原厂提供，我的工作重点是管理业务、协议扩展和多平台适配。

## 跨品牌组网与认证

配合中国联通 EasyMesh 认证测试，涉及华为光猫混合组网、拓扑更新、指定节点一键组网、网络稳定性、4K 视频漫游及 IPv6 测试支持。

平台实现 Qualcomm 与 MediaTek 路由器统一组网，Mesh 能力覆盖公司路由器产品，并支持跨品牌混合组网。

## 组网效果与问题处理

在实际测试中，子路由从按下组网按键开始，到成功入网、公网指示灯点亮，约 1 分钟完成。

在有线回程漫游问题中，客户端已经完成无线重连，但业务流量不能正常转发。我沿 Controller 转发路径检查 ARP 与交换机 FDB 状态，定位二层转发表未及时同步、流量仍发往旧端口的问题，并完成修复。
