## 代表性工作

### AX3000：承担完整产品的软件交付

作为 Qualcomm IPQ5018 平台 AX3000 路由器的软件核心负责人，工作覆盖环境搭建、基板调试、硬件接口验证、U-Boot 与启动流程、eMMC 分区、内核及软件包配置、业务软件移植、工厂对接和上市后维护。

软件团队共 3 人，我负责系统、WiFi、非网络类工具及相关内核模块；其他同事负责产品层面的网口、网络和防火墙。工厂提供硬件及初期软件适配，芯片原厂支持硬件改动所需的软件修改。产品最终量产上市，累计销量数万台，电商平台好评率超过 98%。

### 在 512M 硬件上改善系统资源与业务运行

面对内存压力、频繁换页和高 I/O 等待带来的卡顿，我持续调整 DTS 内存布局、禁用未使用的 WiFi Radio 设备描述、裁剪内核模块，并修复业务程序内存泄漏、减少 C 代码中的 Shell 调用、重构部分功能模块。

在同一款 512M 硬件的新旧系统启动初期对比中，`MemTotal` 从约 310M 增至 430M。系统可识别内存增加约 120M，同时应用运行占用下降，支持 PCDN 业务运行并保障用户体验。因这项工作获得 2024 年上半年无线宝产品部卓越服务奖，并由 P6 晋升 P7。

### ezMesh：跨平台的组网管理业务

负责 ezMesh 管理进程和业务架构，在原厂 IEEE 1905 协议栈上扩展私有 TLV，开发节点管理、心跳、状态同步和组网控制。统一适配 Qualcomm 与 MediaTek 平台，支持按键、App、Web 组网及跨品牌混合组网，配合通过中国联通 EasyMesh 认证。

在实际测试中，子路由从按下组网按键到成功入网、公网指示灯点亮，约 1 分钟完成。也负责处理漫游后转发异常、WiFi 接入和无线稳定性问题，结合空口抓包、系统日志及 Linux 网络状态完成定位。
